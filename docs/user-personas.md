# Target User Personas & Role Matrix

EdgeTrust Control Tower supports 7 distinct enterprise user roles tailored to NBFC operational hierarchies.

---

## 1. CEO (Executive Strategic Vision)
- **Goal**: Understand macro AI performance, ROI payback, compliance risk, and overall agent trust.
- **Key Views**: Executive Dashboard, ROI & Business Impact Panel, High-level Reports.
- **Permissions**: Read-only strategic access across all workspace metrics.

## 2. COO (Chief Operating Officer)
- **Goal**: Monitor operational efficiency, handling time reduction, and human approval workload.
- **Key Views**: Operations Dashboard, Approval Queue, Capacity Funnel.
- **Permissions**: Full operational oversight, escalation approval, agent pause clearance.

## 3. Operations Manager
- **Goal**: Review, edit, approve, reject, or escalate AI-recommended customer actions.
- **Key Views**: Approval Queue, Case Workbench, Case List.
- **Permissions**: Approve, edit draft, reject with reason, escalate case, pause case automation.

## 4. Compliance Manager
- **Goal**: Enforce regulatory policies, audit verifiable evidence, monitor incidents.
- **Key Views**: Policy Engine, Audit Log, AI Incidents, Compliance Reports.
- **Permissions**: Create/edit/disable policies, export audit CSV/PDF, execute incident containment.

## 5. AI Product Manager
- **Goal**: Benchmark agent versions, run evaluation suites, evaluate model quality & latency.
- **Key Views**: Agent Registry, Evaluation Studio, Version Comparison Workbench.
- **Permissions**: Run evaluation simulations, compare release candidates, promote to staging, rollback version.

## 6. Collection Agent
- **Goal**: Handle assigned overdue loan accounts with AI-assisted drafting.
- **Key Views**: Assigned Cases List, Customer Profile, Approved Drafts.
- **Permissions**: View assigned cases, dispatch approved communications, add case notes.

## 7. Admin (SuperAdmin)
- **Goal**: Platform IT administration, user management, security configuration, analytics.
- **Key Views**: All System Routes, Settings, Product Usage Analytics.
- **Permissions**: Full platform access.
